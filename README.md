# 凡人修仙传 · 人界篇（2D 水墨开放世界）

## ⬇ 下载试玩（第一步：人界大地图）
**[点此下载 fanren-step1.zip](https://github.com/qwasx/arena-minmaxh3/raw/arena/01a0d78f-arena-minmaxh3/download/fanren-step1.zip)**

解压后双击 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可（无需安装、无需联网）。

### 操作
- 电脑：WASD / 方向键移动；鼠标点地面自动前往；滚轮缩放；M 世界地图；F 御剑（体验）
- 手机：左下摇杆移动；点地面前往；双指缩放

### 本步内容
标题界面、开场字幕、完整人界大地图（天南 / 乱星海 / 大晋 / 天澜草原 / 极西之地）、神识范围、迷雾探索、时间四季、世界地图、自动存档、手机适配。
设置里有“显示全图 / 御剑 / 地图点选瞬移”体验开关，方便预览整个人界。

## 开发
```
npm install
npm run dev     # 开发预览
npm run build   # 打包到 dist/（可直接双击 index.html 运行）
```
