# 峰不二子 · 巴黎雨夜（The Woman on the Roof）

一个 three.js 做的三渲二 1:64 微缩场景：雨夜的巴黎街角，ÉTOILE 珠宝店刚被盗，
峰不二子站在孟莎屋顶上举着钻石「L'Étoile de Paris」，楼下是钱形警部和警车，
鲁邦在黄色菲亚特 500 里痴痴地望着她。风格参考仓库根目录的 `rainy_konbini.html`。

**成品：[`fujiko_paris.html`](./fujiko_paris.html)**（单个 HTML 文件，约 840 KB，双击就能打开，不需要联网）

## 玩法

| 操作 | 效果 |
| --- | --- |
| 拖动 / 滚轮 / 双指 | 旋转、缩放镜头 |
| 点 **不二子** | 飞吻 + 眨眼 + 撒一张唇印卡片，镜头拉近 |
| 点 **警车** / **直升机** | 拉响警报：法国警笛 pin-pon、探照灯锁定屋顶 |
| 点 **钱形** | 「ルパ〜ン！逮捕だ〜！」 |
| 点 **菲亚特 / 鲁邦** | 闪大灯、按喇叭、鲁邦挥手「ふ〜じこちゃ〜ん♡」 |
| 点 **猫头鹰** | 转头 + 「ホー」（2012 版的猫头鹰彩蛋） |
| 点 **黑猫**、**摩托**、**埃菲尔铁塔**、**天窗**、**广告柱**、**地铁口**… | 各有小反应 |
| 底部按钮 | 下雨 / 警报 / 自动环绕 / 切换视角 / **2012 画风**（排线 + 胶片颗粒）/ 声音 |
| 键盘 | `R` 雨 · `A` 警报 · `O` 环绕 · `V` 视角 · `1`–`6` 视角预设 · `H` 2012 画风 · `M` 声音 |

会动的细节：雨丝、水洼涟漪、落地水花、屋檐先长水珠再滴落、橱窗玻璃上走走停停的水流、
湿地面灯光倒影、旋转警灯的红蓝光、直升机探照灯、沙龙里扫动的激光、钻石闪光、
不二子的头发和风衣随风飘、垂下天窗的绳子、飘落的唇印卡片、TABAC 灯牌接触不良、
红绿灯、埃菲尔铁塔整点闪灯 + 旋转探照灯、窗户随机开关灯、猫头鹰眨眼……

所有声音都是 WebAudio 实时合成的（没有音频文件）；手机上会自动降低画质。

## 开发

```bash
cd fujiko
npm install
npm run dev      # http://localhost:5173 （加 ?q=low 模拟手机画质）
npm run build    # → dist/index.html，再复制成 fujiko_paris.html
```

代码结构：

```
src/
  main.js            渲染器、灯光、主循环
  ui.js              按钮、点击、对话气泡、镜头预设
  audio.js           合成音效
  core/              工具函数、几何合并（减少 draw call）、全局状态
  world/             底座、街道、珠宝楼、咖啡馆、街道家具、载具、角色、灯光、远景
  fx/                雨、地面倒影、2012 画风后期
```

*同人致敬作品。角色造型为原创的简化「手办」版本，未使用任何官方素材或原声音乐。*
