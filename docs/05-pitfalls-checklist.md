# 05 · 常见坑与交付前自检

## 1. 格式层面的坑（校验脚本能抓到）

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 字段名写错 / 少字段 / 顺序错 | 模型读不到结构 | 三字段名逐字：`integrated_multimodal_description` `overall_soundscape` `non_diegetic_music`，顺序固定 |
| `[Shot 1]` 带了时间戳 | 与训练分布不一致 | Shot 1 不写 `At ...` |
| 时间戳格式随意（`3.5s`、`00:03`） | 时间点不被识别 | `At 00:03.500,` 分:秒.毫秒，毫秒三位 |
| 时间戳不递增 / 超出总时长 | 镜头计划自相矛盾 | 严格递增且 < 总时长 |
| 对齐语句不是第一行 / 改了措辞 | 关键帧对齐失效 | 逐字照抄官方三句，第一行，后空一行 |
| FL2VA / L2VA 的 `S.SS` 与实际时长不符 | 尾帧落点错位 | 8 秒写 `8.00`；ComfyUI 124 帧写 `5.17` |
| `<d>` 里塞了动作、语气、说话人 | 会被"读"出来 | `<d>` 里只有 `[语言]` + 原话 |
| `<d>` 没有语言标签 | 语种不稳 | `<d>[Chinese] ...</d>` |
| 画外音没写嘴唇闭合 | 画面角色跟着张嘴 | `says in an off-screen voiceover: <d>...</d> while his lips remain completely closed.` |
| 一句台词跨镜没标 `<scenetrans>` | 台词在切镜处断掉或重复 | 两端都放 `<scenetrans>` + 连续性短语 |
| `overall_soundscape` 里重复对白 / 写配乐 | 声音层打架 | 只写环境音、动作音、非语言人声 |
| `non_diegetic_music` 里写情绪词 | 配乐不可控 | 只写乐器 / 速度 / 节奏 / 动态 |
| 主体里夹中文描述 | 模型主体是英文训练的 | 描述全英文，只有 `<d>` 内和 `"..."` 内保留原语言 |
| 屏幕文字没加双引号 | 糊成乱码 | 每条文字 `"..."` 单独写出 |
| Ref2VA 标签没定义就用 / 定义了不用 | 参考关系断裂 | `subject_definitions` 定义齐，后文都引用 |
| Ref2VA summary 任务类型拼错 | 结构不合规 | 只用六个固定值，用 ` + ` 组合 |
| `retention_analysis` 里写 `(Sx)` | 违反规范 | 说话人 ID 只在 detailed_description |
| 音频保留标记用错集合 | 口型不对 | Audio 用 `fully_copy / partially_copy / reference / weak_reference` |
| 提示词超过 7000 字符 | API 拒绝 | 精简 |

## 2. 内容层面的坑（脚本抓不到，靠自己）

| 坑 | 表现 | 对策 |
| --- | --- | --- |
| 只写"拍个 XX 的视频" | 模型自由发挥 | 按三字段 / 六段式写全 |
| 抽象形容词堆砌 | "cinematic, beautiful, stunning" 没有可执行信息 | 换成可见 / 可听的具体细节：光从哪来、什么材质、什么声音 |
| 切镜没带新信息 | 画面跳一下但什么都没变 | 只想变距离就用运镜 |
| 时长和动作量不匹配 | 慢动作 / 动作被砍 | 按真实耗时预算（见 04） |
| 台词太长 | 语速失真、片尾截断 | 中文 ~4 字/秒，英文 ~2.5 词/秒，留半秒反应 |
| 用否定句 | 无效 | CFG 蒸馏模型没有负面提示，正着写 |
| 靠文字锁脸 | 换镜头就换人 | 用 Ref2VA + 多角度参考图 |
| 参考没分工 | 模型不知道哪张图管什么 | 每个参考在 `subject_definitions` 里明确角色 |
| 参考视频比目标长 | 后半段编排丢失 | 参考会被截到目标时长，先剪好 |
| 文字和图打架 | I2VA 出片风格分裂 | 从图里推导风格、光线、色调 |
| FL2VA 首尾差异不可插值 | 中间"变形" | 差异控制在同场景同主体；否则多镜头或 Ref2VA |
| 光线每镜重新定义 | 光跳 | 只在 Shot 1 定义一次 |
| 左右方向没钉 | 角色换手、换边 | 写 `stays on the left of frame throughout` |
| 一次就想出 15 秒长片 | 废片率高 | 先 5 秒试跑验证提示词，再拉长 |

## 3. 交付前自检清单（打印版）

**所有模式**
- [ ] 模式判断正确（图是"起始帧"还是"参考角色"想清楚了）
- [ ] 总时长确定（API：4–15 整数秒；ComfyUI：17k+5 帧对应的秒数）
- [ ] 字段齐全、顺序正确、拼写正确
- [ ] `[Shot 1]` 无时间戳，后续 `At MM:SS.mmm,` 严格递增、小于总时长
- [ ] 每个切镜带来新信息
- [ ] 风格词出现在开头（基础模式在 Shot 1 内；Ref2VA 在 Shot 1 前）
- [ ] 每个说话人：首次出现有声音画像，`(Sx)` 稳定，`<d>[语言] 原话</d>`
- [ ] 画外音：固定短语 + 嘴唇闭合
- [ ] 跨镜台词：两端 `<scenetrans>` + 连续性短语
- [ ] 屏幕文字逐条双引号
- [ ] `overall_soundscape` 1–4 句、不含对白 / 配乐
- [ ] `non_diegetic_music` 1–3 句、无情绪词，或 `N/A`
- [ ] 主体英文，无否定句
- [ ] 总字符 ≤ 7000
- [ ] `python tools/validate_prompt.py 文件 --duration N` 零错误

**关键帧模式追加**
- [ ] 对齐语句第一行、逐字一致、`N` 与最后镜头号一致、`S.SS` 与时长一致
- [ ] I2VA：从图中姿势 / 构图自然起始；风格与图一致
- [ ] FL2VA：写的是路径不是两张图；单镜头优先
- [ ] L2VA：`<Picture 1>` 属于最后一镜；描述如何收敛

**Ref2VA 追加**
- [ ] 每个参考在 `subject_definitions` 有定义、有分工；身份在 `<Subject>` 不在独立 `<Picture>`
- [ ] 区分性细节（痣、疤、纹身、发长、配饰）按位置正着写出
- [ ] `summary` 前缀只用六个合法任务类型；视频编辑以固定句开头
- [ ] `retention_analysis` 每标签一行、标记集合正确、无 `(Sx)`
- [ ] 对口型复用音频 → `fully_copy`
- [ ] `detailed_description` 约 350–500 词（生成类）
- [ ] 标签编号与上传 / 连线顺序一致
