# 04 · 导演手册：格式之上，怎么让片子好看

> 格式规范决定"模型能不能读懂"，导演思维决定"读懂之后好不好看"。
> 官方规范只管前者，这一篇是后者。内容综合了社区经验和通用影视语言，按 H3 的 4–15 秒体量做了取舍。

## 1. 动笔前先回答三个问题

1. **高概念**：一句话说清这条片是什么。"一瓶香水在黑暗里被光找到" vs "一瓶香水的产品展示"——前者能推出镜头，后者推不出。
2. **目标情绪**：观众看完记住什么感觉。高级 / 压迫 / 温暖 / 好笑 / 酷。
3. **情绪弧线**：15 秒以内也要有起承转合，转折点在第几秒。

不能服务弧线的镜头，砍掉。H3 一条片就 4–15 秒，**每个镜头只干一件事**。

## 2. 先定时长，再拆镜头

### 2.1 按真实世界时间给动作预算

时长会被模型字面理解为事件速度：3 秒的动作塞进 10 秒的片，得到的是慢动作，不是留白。先给每个动作估真实耗时，加约 1 秒收尾，再取总时长。

| 事件 | 真实耗时 |
| --- | --- |
| 眨眼、微笑、一惊 | 0.3–0.5 s |
| 枪响、摔门、响指 | < 0.3 s |
| 转头、回眸 | 0.5–0.8 s |
| 摔倒、撞击 | 0.4–0.6 s |
| 抬手、伸手拿东西 | 0.8–1.2 s |
| 一步 | ~0.5 s |
| 走进画面穿过房间 | 2–3 s |
| 一个"看得出是刻意的"慢速运镜 | 1.5–2.5 s |
| 结尾定格让动作沉淀 | 1–2 s |
| 中文口语 | 约 4 字 / 秒（含自然停顿按 3–3.5 字 / 秒估） |
| 英文口语 | 约 2.5–2.7 词 / 秒 |
| 日语口语 | 约 6–7 音节 / 秒 |

### 2.2 时长与镜头数的经验组合

| 总时长 | 建议镜头数 | 典型结构 |
| --- | --- | --- |
| 4–5 s | 1 | 一个动作 + 一个运镜（产品特写、表情反应、Loop 素材） |
| 6–8 s | 1–2 | 建立 → 动作 → 落定；或者一句对白 + 一个反应 |
| 8–10 s | 2–3 | 定场 → 推进 → 收尾；两人各一句对白 + 反应镜头 |
| 10–15 s | 3–5 | 定场 → 建立 → 推进 → 高潮 → 余韵；MV 段落、预告片节奏 |

一个镜头低于 1 秒只适合快切蒙太奇；对白镜头至少留够"说完 + 0.5 秒反应"。

### 2.3 情绪弧线模板（以 12 秒为例）

```
0–3 s   定场：环境、主角、光线，运镜慢
3–8 s   推进：动作 / 对白发生，切镜带来新信息
8–10 s  高潮：最强的动作 / 最近的景别 / 声音最满
10–12 s 余韵：拉远或定格，声音抽空，字幕落下
```

## 3. 景别 = 镜头任务

| 景别 | 英文 | 干什么用 |
| --- | --- | --- |
| 大远景 / 定场 | extreme wide / establishing shot | 交代环境与尺度 |
| 远景 | wide shot | 人物与环境的关系 |
| 全景 | full shot | 完整动作，建立空间 |
| 中景 | medium shot | 对话、动作主体 |
| 近景 | close-up | 情绪、细节 |
| 特写 | extreme close-up | 强调、符号、关键时刻 |

规则：
- 远 → 近是**聚焦**，近 → 远是**揭示**。
- 景别反差是剪辑冲击的来源；所有镜头都停在中景 = 平铺直叙。
- 小细节（纹身、痣、文字）在远景里读不出来；要它被看见就给近景，并明确写"清晰可见"。

## 4. 运镜 = 类型 + 幅度 + 速度 + **动机**

官方要求写清前三项，导演层再加第四项——为什么动。

| 运镜 | 动机 |
| --- | --- |
| Push In / Zoom In | 逼近、聚焦、心理压迫 |
| Pull Out / Zoom Out | 揭示环境、疏离、收尾 |
| Pan | 扫视关系、追踪方向、揭示画外 |
| Truck | 平移跟随、并行感 |
| Tilt Up / Down | 揭示高度、权力关系、从脚到脸的"介绍" |
| Pedestal | 升起 = 开阔 / 神性；下降 = 落地 / 压抑 |
| Arc Shot | 环绕揭示、掌控感、产品展示 |
| Tracking Shot | 跟随、陪伴、沉浸 |
| Static Shot | 稳定、压抑、仪式感、让表演说话 |
| Shake | 不安、纪实、冲击 |
| POV | 代入主体视角 |
| Roll | 失衡、眩晕、风格化转场 |

规则：
- 一条片选 **1–2 种运镜语言用到底**，风格才统一。
- 慢速小幅度是万能安全牌；大幅度快速只留给高潮或转场。
- 镜头本身的运动是模型较弱的轴（社区实测），复杂运镜考虑用 Ref2VA 给一段参考视频借运镜，比纯文字稳。

## 5. 机位、轴线、衔接

- **180° 轴线**：两人对话 / 对峙时机位守在两人连线同一侧，画面左右关系不翻转。写法：在 Shot 1 就钉死 `she stands on the left of frame and he on the right, and this arrangement is kept in every shot`。
- **正反打**：过肩镜头各占一侧，别双双居中。
- **视线匹配**：人物看画外 → 下一镜给他看的东西。
- **动作衔接**：在动作进行到一半时切（转身、抬手），隐藏剪辑点。
- **匹配剪辑**：下一镜用相似构图 / 形状 / 运动接上一镜。
- **J-cut（声音先入）**：下一镜的声音比画面早半秒进来。写法：`the ring of the doorbell from the next scene is already audible before the cut`。
- **静音呼吸**：高潮前把声音抽空一拍再爆发，冲击翻倍。写法：在 `overall_soundscape` 里写 `all ambience drops out for half a second before the impact`。

## 6. 连续性：逐条锁死

写完一版，用这张表自检。H3 的时长短，一次崩就是整条废。

| 维度 | 检查 | 对策 |
| --- | --- | --- |
| 身份 | 脸 / 发型 / 服装 / 配饰跨镜头一致 | 参考图走 Ref2VA；文字里把特征写死；说话人 ID 跨镜统一 |
| 空间 | 物体相对位置、站位不跳 | 写明 `stays on the left of frame throughout` |
| 动作 | 跨镜动作从上一镜结尾续接 | 写 `continuing the motion from the previous shot` |
| 光线 | 光源方向、色温一致 | 只在 Shot 1 定义一次（`warm key light from the upper left`），后续引用 |
| 色调 | 同一场景调色统一 | 颜色词只在首镜定义，别逐镜乱改 |
| 时间 | 时序清楚、无莫名跳变 | 切镜时间递增；跳时间要有理由（叠化、字幕） |
| 左右 | 角色的右手在画面左侧 | 用不会翻的地标（手表、纹身）锁边；写明 `never changes hands` |

高频翻车与对策：
- **人脸漂移** → 别指望纯文字锁脸，上 Ref2VA + 2–4 张不同角度参考图合并成一个 `<Subject>`。
- **物体凭空消失** → 每个它应该在的镜头都提一句。
- **方向反转** → 钉一句站位。
- **光线跳变** → 光源只定义一次。
- **文字乱码** → 每条屏幕文字逐条双引号写出。
- **否定句无效** → "不要水印 / 不要多余的手"没用，正着写想要的。

## 7. 声音设计：H3 的独门武器

H3 的音频是和画面一起生成的，声音写得好坏直接影响观感。

1. **环境音是主角**。先写 `overall_soundscape`——场景底噪是什么（室内底噪 / 街道 / 雨），再加物理动作音（脚步、布料、碰撞），最后才是配乐。
2. **画内 vs 画外要分清**。角色能听到的（收音机、现场乐队、手机外放）是画内音，写在主体描述里；只有观众听到的配乐才是 `non_diegetic_music`。
3. **配乐只写"是什么"，不写"为了什么"**。乐器 + 速度 + 节奏 + 动态变化：`a clean electric-guitar arpeggio at a moderate tempo, joined by brushed drums after the cut, dropping to a single sustained pad on the final shot`。"sad piano" 这种写法是错的。
4. **让情绪线驱动配乐的动态**：安静 → 紧张 → 爆发 → 余韵，落到"何时进 / 何时起 / 何时收"。
5. **对白要留呼吸**。一句话说完至少半秒反应；两人对话别让台词首尾相接。
6. **声音先入、静音呼吸**：见第 5 节。
7. **立体声**可以用方位词：`a car passes from left to right`、`footsteps approach from behind the camera`。

## 8. 对白写作要点

- 台词越短越稳。4–15 秒里，一句 6–12 个字的中文 / 8–15 个英文词的台词最从容。
- 先给声音画像再给台词：年龄 / 性别 / 音高 / 音色 / 语速 / 口音 / 情绪状态。`the young woman with a clear, slightly hurried voice (S1)`。
- 说话时的动作和表情写在 `<d>` 外面：`glances at the bag strap, then meets her eyes, and ... answers:`。
- 一句话要跨镜头才切，用 `<scenetrans>`；不需要就别切在台词中间。
- 中文台词里的语气词、省略号、标点都会被"读"出来，所以要写得像人说的话，不要写成书面语。

## 9. 关键帧模式的导演注意点

- **I2VA**：参考图决定风格和构图，别在文字里和图打架（图是暖光，别写冷光）。动作从图里的姿势自然起始。
- **FL2VA**：两张图之间的差异要"可插值"——同一场景、同一主体、姿势变化在 8 秒内合理。差异太大就改用多镜头并明确说明，或换 Ref2VA。
- **L2VA**：倒推出的开场要和尾帧同一空间、同一光线；描述"如何逐渐变成尾帧"而不是描述尾帧本身。

## 10. 速查：导演一句话版

- 定场 → 建立 → 推进 → 高潮 → 收尾
- 远 → 近是聚焦，近 → 远是揭示
- 推是逼近，拉是疏离，跟是陪伴，摇是环顾
- 轴线别跨，方向别翻，光线别跳
- 静音呼吸，声音先入，动作中切
- 三字段定骨架，导演层填血肉
